# Way of Working

## Branches

The `main` branch contains the stable version of the project. New features and changes are developed in separate branches.

Examples:

* `feature/pico-sensors`
* `feature/mqtt`
* `feature/database`
* `feature/grafana`
* `docs/way-of-working`

## Commits

Commits should be small and describe what was changed.

Examples:

* `feat: add BME280 sensor`
* `feat: add MQTT connection`
* `fix: handle MQTT reconnect`
* `docs: add way of working`

## Pull Requests

Changes are merged into `main` through pull requests. At least one other team member should review the code before the pull request is merged.

## Issues

Larger tasks are created as GitHub Issues. Each issue should describe what needs to be done.

## Collaboration

All team members should contribute through relevant commits, pull requests, code reviews and documentation.

## Definition of Done

A task is considered done when the implementation works, has been tested, documented when necessary, reviewed and merged into `main`.
