# πCo — Smart Grow Environmental Monitor

An edge-computing and IoT telemetry project built around a **Raspberry Pi Pico W**. The device monitors environmental conditions, evaluates threshold rules locally, and publishes readings to a containerized data pipeline for storage, visualization, and remote alerting.

## At a glance

- **Edge device:** Raspberry Pi Pico W running MicroPython.
- **Sensors:** DHT11 temperature/humidity sensor and APDS-9999 light sensor.
- **Local feedback:** LCD status display, buzzer, and LED.
- **Messaging:** MQTT via Mosquitto (QoS 1).
- **Data pipeline:** Python consumer and TimescaleDB.
- **Visualization:** Grafana.
- **Remote notifications:** Discord webhook alerts.

## Architecture

```text
Pico W + sensors
      |
      | Wi-Fi / JSON over MQTT
      v
Mosquitto broker
      |
      v
Python consumer -----> Discord webhook
      |
      v
TimescaleDB
      |
      v
Grafana dashboard
```

The Pico W evaluates configured environmental thresholds on the device. This means local alarms can be triggered without waiting for a remote service. Telemetry is also published over MQTT for downstream storage and monitoring.

## Key features

- Local threshold checks for temperature, humidity, and light conditions.
- Audible and visual alerts using the buzzer and LED.
- LCD display for local system status.
- MQTT publishing and reconnect handling for intermittent Wi-Fi or broker outages.
- Python-based ingestion into TimescaleDB.
- Grafana dashboard for viewing collected readings.
- Discord notifications generated by the consumer when alert flags are received.

## Quick start

### 1. Start the pipeline

Install Docker and Docker Compose, then from the pipeline directory:

```bash
cd src_pipeline
cp .env.example .env
```

Add the required local database, Grafana, and Discord webhook settings to `.env`, then run:

```bash
docker compose up -d --build
```

The consumer is configured to wait for its dependencies and then subscribe to MQTT messages.

### 2. Configure the Pico W

1. Create the local Wi-Fi credentials file expected by the device code.
2. Set the MQTT broker address to the host's reachable LAN address.
3. Copy the MicroPython device files to the Pico W using your preferred tool (for example, Thonny or the VS Code MicroPico extension).
4. Run `main.py` on the device.

Do not commit Wi-Fi credentials or webhook tokens.

### 3. View telemetry

Open the Grafana instance at the local address and port configured in the Compose file. Use the credentials from your local environment configuration.
